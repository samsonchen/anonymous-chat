## 2. 方向

- 手機優先，電腦版是同一組元素重新排版。
- 淺色，一個主色（紅色）。
- 風格欄位在 `/design` 指令裡沒有填，以上是我先決定的。要換成深色或其他風格，需要整組重做顏色。
- 沒有使用任何設計系統。帳號裡唯一的一個（Course Deck）是簡報用的，不適合。

## 3. 顏色

| 變數 | 色碼 | 用在哪裡 |
|---|---|---|
| `--bg` | `#F7EFEC` | 整個畫面的底色 |

| `--ink` | `#1F0B0B` | 主要文字 |

| `--field-border` | `#B07872` | 輸入框邊框（預設） |
| `--accent` | `#C8102E` | 主色：按鈕、自己的訊息、聊天室頂端列、「已送達」 |

| `--accent-disabled` | `#DC7A82` | 「連線中…」按鈕底色 |
| `--disabled-bg` | `#EBD5D1` | 停用的「送出」按鈕底色（文字用 `--muted`） |

| `--error` | `#B54708` | 錯誤文字與錯誤邊框（橘褐色） |
| `--error-soft` | `#FFEDD5` | 錯誤提示條、送出失敗泡泡的底色 |

白字用在 `--accent` 上，文字對比約 5.9:1。

## 4. 字體與尺寸

**字體**

- 中文與一般文字：Noto Sans TC（字重 400、500、700），Google Fonts 載入。後備是系統字體。
- 時間、字數：IBM Plex Mono（字重 400、500）。

```
https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500&family=Noto+Sans+TC:wght@400;500;700&display=swap
```

**字級**

| 用途 | 大小 | 字重 |
|---|---|---|
| 進入畫面標題 | 34px | 700 |
| 聊天室標題（手機 / 電腦） | 17px / 18px | 700 |
| 進入畫面說明、按鈕文字 | 16–17px | 400 / 700 |
| 訊息內容 | 15px，行高 1.55 | 400 |
| 輸入框（手機） | 16px | 400 |
| 代號、一般標籤 | 13–14px | 700 / 500 |
| 時間、字數、小字 | 12–13px | 400 |

輸入框字級在手機上固定 16px，避免 iPhone 輸入時自動放大畫面。

**尺寸規則**

- 所有可以點的東西，高度或寬度至少 44px（頂端列按鈕、送出、重試、重送、重新整理、關閉）。
- 手機頂端列高 64px；展示模式提示條高約 36px。
- 手機畫面左右留白 16px（進入畫面 24px）。
- 訊息泡泡最大寬度：手機 86%、電腦 75%。電腦版訊息欄最大寬度 720px，置中。
- 電腦版名單欄寬 280px，手機名單抽屜寬 300px。
- 圓角：輸入框與按鈕 12px、泡泡 14px（靠近發言者那一角 4px）、名單項目 10px。

## 5. 各畫面的元素

### 5.1 進入畫面

由上到下：

1. **展示模式提示條**（階段一才有）：深酒紅底，左邊資訊圖示，文字「展示模式：訊息只存在你的瀏覽器，別人看不到。」
2. **標題區**：48px 紅色圓角方塊（對話框圖示）、標題「匿名聊天室」、一行說明「不用註冊、不用登入。取一個代號就能進來，所有人都在同一間。」
3. **代號輸入框**：上方標籤「你的代號」，輸入框高 52px。下方左邊「1–12 個字，前後空白會自動去掉」，右邊字數「2 / 12」（等寬字）。
4. **錯誤文字區**：固定保留一行高度，沒有錯誤時是空的，避免出現錯誤時畫面跳動。有錯誤時：圖示 + 橘色文字，輸入框邊框變 2px 橘色。
5. **「進入聊天室」按鈕**：滿版，高 52px，紅底白字。

**狀態**

| 狀態 | 輸入框 | 錯誤區 | 按鈕 |
|---|---|---|---|
| 預設 | 預先填好上次的代號，邊框 `--field-border` | 空 | 紅底，可按 |
| 代號已被使用 | 2px 橘色邊框 | 「這個代號已被使用，請換一個。」 | 可按 |
| 被踢出（代號衝突） | 同上 | 「你的代號被別人先用了，請換一個代號再進來。」 | 可按 |
| 連線中 | 停用（淺底、淡邊框） | 空 | `--accent-disabled` 底，轉圈圖示 + 「連線中…」，不可按 |

電腦版：同樣的內容放在寬 440px 的白色卡片裡，卡片置中，提示條在最上方。

### 5.2 聊天室：頂端

- **展示模式提示條**：同進入畫面，聊天室頂端也要有。
- **頂端列**：紅底（`--accent`）白字。
  - 標題「匿名聊天室」。
  - 手機：半透明白底的膠囊按鈕「● 12 人在線」，按下打開名單。名單打開時膠囊變白底、深紅字，並設 `aria-expanded="true"`。
  - 電腦：「● 12 人在線」只是文字，不能按。
  - 「離開」：手機是白字純文字按鈕；電腦是透明底、半透明白邊框、帶離開圖示的按鈕。

### 5.3 聊天室：訊息列表

訊息由下往上排，列表貼近輸入區。

| 元素 | 外觀 |
|---|---|
| 別人的訊息 | 靠左。上方一行：代號（13px，粗體）+ 時間（等寬 12px，`--muted`）。下方白色泡泡，邊框 `--line`，左上角圓角 4px |
| 自己的訊息 | 靠右。上方一行：狀態 + 時間。下方紅色泡泡白字，右上角圓角 4px |
| 系統提示 | 置中，13px，`--muted`，沒有泡泡，沒有時間，例如「Mei 進來了」「小明 離開了」 |
| 內容 | 保留換行（`white-space: pre-wrap`），長字串強制折行（`overflow-wrap: anywhere`），網址只是純文字，沒有底線或連結顏色 |

**自己的訊息狀態**

| 狀態 | 上方一行 | 泡泡 |
|---|---|---|
| 送出中 | 轉圈圖示 + 「送出中」（`--muted`） | 紅底，透明度 0.75 |
| 已送達 | 勾勾圖示 + 「已送達」（`--accent`） | 紅底 |
| 送出失敗 | 圓圈驚嘆號 + 「送出失敗」（`--error`，粗體） | `--error-soft` 底、`--error` 邊框、深色文字；泡泡下方有「重送」按鈕（橘色邊框、重新整理圖示） |

**列表狀態**

| 狀態 | 外觀 |
|---|---|
| 空白 | 虛線框，置中文字「還沒有訊息」 |
| 載入歷史失敗 | 白底圓角框，「無法載入歷史訊息」+「重試」按鈕（紅色邊框，紅色文字） |
| 往上看舊訊息時有新訊息 | 列表底部置中的紅色膠囊按鈕「↓ 有新訊息」，有陰影，高 44px |

### 5.4 聊天室：連線狀態列

放在頂端列下方，只在不正常時出現。高度至少 44px，圓角 10px（實作成貼齊畫面寬度時可以去掉圓角）。

| 狀態 | 底色 / 文字色 | 內容 |
|---|---|---|
| `connecting` | `--panel-bg` / `--ink` | 轉圈圖示 + 「連線中…」 |
| `reconnecting` | `--warn-bg` / `--warn-ink` | 圓圈驚嘆號 + 「連線中斷，重新連線中…」 |
| `offline` | `--error-soft` / `--error-ink` | 圓圈驚嘆號 + 「無法連線」+ 「重新整理」按鈕（邊框按鈕，高 44px） |

### 5.5 聊天室：上線名單

- **標題**：「在線 12」，數字用等寬字。
- **列表**：每列高 44px（手機）或 40px（電腦），左邊綠色小圓點，右邊代號。
- **自己**：排在最上面，`--accent-soft` 底，代號粗體，後面接「（你）」（`--accent-dark`，字重 500）。其他人依進入時間排。
- **手機抽屜**：從右邊蓋在畫面上，寬 300px，白底，左側有陰影。標題列右上角有關閉按鈕（44 × 44，X 圖示，`aria-label="關閉"`）。後面是暗色遮罩（`--backdrop`），遮罩本身是一個真正的按鈕（`aria-label="關閉上線名單"`），點外面可以關。
- **電腦**：固定在右側，沒有關閉按鈕，標題列高 56px。

### 5.6 聊天室：輸入區

| 元素 | 外觀 |
|---|---|
| 文字輸入框 | 最小高度 44px（手機）/ 48px（電腦），圓角 12px，邊框 `--field-border`。可多行，不可手動拉大（`resize: none`） |
| 「送出」按鈕 | 手機：最小寬 68px、高 44px。電腦：最小寬 84px、高 48px，帶向上箭頭圖示。可送時紅底白字；空白或連線不正常時停用（`--disabled-bg` 底、`--muted` 字） |
| 字數 | 接近上限才出現，輸入框下方靠右，等寬字：「已輸入 463 / 500」。輸入中的輸入框邊框變 2px 紅色 |
| 錯誤提示 | 在輸入框上方，`--error-soft` 底、`--error-ink` 字、圖示 + 文字，圓角 10px。三種：「請稍等一下再送」「訊息最多 500 字，請縮短一點」「送出失敗，請再試一次」。幾秒後消失，輸入內容保留 |
| 操作提示（電腦） | 輸入框下方 12px 小字：「Enter 送出，Shift+Enter 換行」 |

## 6. 實作時要注意的地方

**對應到架構文件的元件**

| 設計稿 | 元件（`docs/architecture.md` 第 11 段） |
|---|---|
| 進入畫面 | `screens/JoinScreen.tsx`、`components/DemoBanner.tsx` |
| 聊天室畫面 | `screens/ChatScreen.tsx` |
| 頂端列 | `components/TopBar.tsx` |
| 連線狀態列 | `components/ConnectionBanner.tsx` |
| 上線名單 | `components/OnlineList.tsx`（手機是抽屜，電腦是側欄，同一個元件兩種排法） |
| 訊息列表、單則訊息、系統提示 | `MessageList.tsx`、`MessageItem.tsx`、`SystemNotice.tsx` |
| 輸入區 | `components/Composer.tsx` |

**可及性（無障礙）**

- 按鈕一律用真正的 `<button>`，輸入框一律搭配 `<label>` 或 `aria-label`；不要在 `div`、`span` 上加點擊事件。
- 只有圖示的按鈕要有 `aria-label`。裝飾用的圖示加 `aria-hidden="true"`。
- 錯誤文字區和錯誤提示用 `role="alert"`；連線狀態列用 `role="status"`（`offline` 用 `role="alert"`）。
- 代號輸入框有錯誤時加 `aria-invalid="true"`，並用 `aria-describedby` 指向錯誤文字。
- 顏色不是唯一的區分方式：錯誤一律有圖示和文字，訊息狀態一律有文字。

**其他**

- 圖示在設計稿裡是內嵌 SVG（線條圖示，2px 線寬，圓角端點）。實作時不需要圖示套件，用同樣方式內嵌即可。
- 設計稿上的電腦版與手機版斷點沒有指定。建議以約 768px 為界：以下用手機排法（名單抽屜），以上用電腦排法（名單側欄）。
- 設計稿只畫了靜態畫面，沒有動畫。抽屜開關、新訊息出現、狀態列出現，都沒有指定動畫，要不要加由實作時再決定。
- 淺色是唯一的配色，沒有做深色版本。

## 7. 設計稿與架構文件的差異

- **聊天室頂端的展示模式提示**：`docs/architecture.md` 第 4.1 段寫了要有，但第 7.2 段的聊天室元素清單沒有列。設計稿裡有，之後可以把它補進第 7.2 段。
- **「離開」按鈕**：兩份文件一致，原始需求沒有，是架構文件加上的。
- **名單裡的在線小圓點、已送達的勾勾、轉圈圖示**：第 7 段沒有提到，是設計時補上的外觀細節，不影響行為。
- **載入失敗與空白狀態的文字**：「還沒有訊息」「無法載入歷史訊息」沿用架構文件。「請稍等一下再送」沿用，「訊息最多 500 字，請縮短一點」「送出失敗，請再試一次」是設計時寫的，可以改。
